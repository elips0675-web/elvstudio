1. ОТВЕТ ПО БЛОГУ И YOAST SEO
--------------------------------------------------------------------------------
Вердикт: Сам блог остаётся строго БЕСПЛАТНЫМ ($0) как воронка установок.
Вся SEO-логика с Yoast-анализатором выносится в отдельный плагин Elv.Seo ($20-25).

Почему нельзя продавать «Блог + SEO» единым плагином:
- Конкуренция: В каталоге есть RainLab.Blog (173k+ установок, бесплатно).
  Разработчики не меняют привычный блог ради встроенного SEO.
- Архитектура: Если блог привязан к твоим Tailor blueprints, на чужой теме он
  не заведётся. SEO-плагин должен работать с любыми моделями и страницами.
- Алгоритм каталога: Платный плагин с 0 установок никто не найдёт (пример —
  BlogPlus). Бесплатный Elv.Blog качает установки и внутри админки рекомендует
  платный Elv.Seo.

2. КАК РАСПИЛИТЬ МОНОЛИТ plugins/elv/library НА НЕЗАВИСИМЫЕ ПАКЕТЫ
--------------------------------------------------------------------------------
Сейчас весь код живёт в одном плагине Elv\Library. Для маркетплейса разнеси его
на 5 чистых пакетов:

plugins/elv/
├── blog/       [FREE $0]   Tailor blueprints + BlogContent seeder + RSS + теги
├── search/     [FREE $0]   BM25/стемминг-индекс + elv:search-index + AntiSpam
├── seo/        [PAID $25]  SeoAnalyzer (Yoast-скоринг), JSON-LD, Sitemap, 301
├── bookings/   [PAID $49]  Slot, BookingService (lockForUpdate), REST API слотов
└── store/      [PAID $79]  OrderService + PaymentManager (Stripe/ЮKassa) + LicenseService

Как сделать Elv.Seo универсальным (под любой проект покупателя):
1) Расширяем модели через полиморфную связь morphOne в Plugin.php:
   \RainLab\Blog\Models\Post::extend(function ($model) {
       $model->morphOne['seo_meta'] = [\Elv\Seo\Models\Meta::class, 'name' => 'seoable'];
   });

2) Добавляем поддержку Tailor (October CMS 3.x / 4.x) через Mixin:
   Покупатель подключает в своём blueprint:
   seo:
       type: mixin
       source: Elv\Seo\Blueprints\SeoMixin

3) Что проверяет Yoast-виджет в админке (FormWidget на чистом JS без внешних API):
   - Наличие и плотность ключевого слова в title, H1, первом абзаце, meta_description
   - Длину сниппета в символах/пикселях
   - Наличие атрибута alt у изображений и внутренних ссылок
