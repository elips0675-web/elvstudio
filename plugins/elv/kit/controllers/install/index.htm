«Применить миграции» создаёт недостающие таблицы. Повторный запуск безопасен: существующие таблицы и записи не удаляются.

«Загрузить демо-данные» добавляет товары, категории, статьи и свободное время только там, где записей ещё нет. Ваши статьи и товары не перезаписываются.

Очередь писем обрабатывается кнопкой «Обработать очередь», если на хостинге не настроен планировщик. Для постоянной работы настройте cron в панели хостинга.
