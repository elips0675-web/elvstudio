🔑 «Стучалка» установок с проверкой Ключа (License Key)

Обновленное руководство. Добавление механизма Ключа активации (License Key) превращает простую «стучалку» в надежную систему защиты от накрутки и nulled-версий, считая только реальные покупки.

01 Архитектура с использованием Ключа

Теперь система работает по принципу "Запрос + Валидация":

  1. Клиент (October CMS): Администратор вводит купленный ключ в настройках плагина. При сохранении или первом запуске плагин отправляет ключ + хэш домена на ваш сервер.
  2. Сервер (API): Проверяет наличие ключа в базе данных продаж, сверяет привязанный домен (если есть) и только при успехе засчитывает установку.
  3. Фронтенд (Витрина): Показывает количество валидных установок, что является мощным социальным доказательством для покупателей.

02 Шаг 1: Настройка и код плагина (с Ключом)

1. Создайте файл конфигурации config/fields.yaml для ввода ключа в админке October CMS:

# plugins/yourvendor/yourplugin/config/fields.yaml
fields:
    license_key:
        label: Ключ активации
        comment: Введите ключ, полученный при покупке на ourstore.com
        type: text
        span: full

2. Обновите метод boot() в Plugin.php. Теперь он проверяет наличие ключа перед отправкой:

<?php namespace YourVendor\YourPlugin;

use System\Classes\PluginBase;
use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\Http;
use System\Models\Setting; // Для получения ключа из настроек

class Plugin extends PluginBase
{
    public function pluginDetails() { /* ... */ }

    public function boot()
    {
        $cacheKey = 'yourvendor_yourplugin_license_reported_v1';

        // Стучим только если еще не делали этого
        if (!Cache::has($cacheKey)) {
            // Получаем ключ из системных настроек плагина
            $licenseKey = Setting::get('yourvendor_yourplugin.license_key', '');

            if (!empty($licenseKey)) {
                try {
                    $domainHash = request() ? hash('sha256', request()->getHost()) : 'unknown';

                    $response = Http::timeout(3)->post('https://api.yourstudio.com/v1/activate', [
                        'plugin'      => 'YourVendor.YourPlugin',
                        'version'     => $this->pluginDetails()['version'] ?? '1.0.0',
                        'domain_hash' => $domainHash,
                        'license_key' => $licenseKey, // Отправляем ключ для валидации
                        'api_token'   => env('MARKETPLACE_API_TOKEN', 'your_super_secret_token')
                    ]);

                    if ($response->successful()) {
                        // Успешная активация: кэшируем на год
                        Cache::put($cacheKey, true, now()->addYear());
                    }
                } catch (\Exception $e) {
                    // Игнорируем ошибки сети, чтобы не ломать сайт клиента
                }
            }
        }
    }
}

03 Шаг 2: Серверный API с валидацией Ключа

Сервер теперь не просто считает запросы, а проверяет, является ли ключ действительным и не использовался ли он на подозрительном количестве доменов.

<?php
// api/activate.php
header('Content-Type: application/json');

$data = json_decode(file_get_contents('php://input'), true);

// 1. Проверка внутреннего токена API (защита эндпоинта)
if (!isset($data['api_token']) || $data['api_token'] !== 'your_super_secret_token') {
    http_response_code(403);
    echo json_encode(['status' => 'error', 'message' => 'Unauthorized API access']);
    exit;
}

// 2. Валидация ключа в базе данных продаж
$licenseKey = $data['license_key'] ?? '';
$pluginSlug = preg_replace('/[^a-zA-Z0-9.]/', '', $data['plugin'] ?? '');
$domainHash = $data['domain_hash'] ?? '';

$pdo = new PDO('mysql:host=localhost;dbname=marketplace', 'user', 'pass');

// Проверяем ключ
$stmt = $pdo->prepare("SELECT id, status, max_domains FROM licenses WHERE license_key = :key AND plugin_slug = :plugin");
$stmt->execute(['key' => $licenseKey, 'plugin' => $pluginSlug]);
$license = $stmt->fetch(PDO::FETCH_ASSOC);

if (!$license || $license['status'] !== 'active') {
    http_response_code(403);
    echo json_encode(['status' => 'error', 'message' => 'Invalid or revoked license key']);
    exit;
}

// 3. Проверка лимита доменов (защита от массовой раздачи одного ключа)
$domainStmt = $pdo->prepare("SELECT COUNT(DISTINCT domain_hash) as count FROM plugin_installs WHERE license_id = :lid");
$domainStmt->execute(['lid' => $license['id']]);
$domainCount = $domainStmt->fetch(PDO::FETCH_ASSOC)['count'];

if ($domainCount >= $license['max_domains']) {
    http_response_code(403);
    echo json_encode(['status' => 'error', 'message' => 'Domain limit reached for this key']);
    exit;
}

// 4. Успех: регистрируем установку (игнорируем дубликаты для одного домена)
$insertStmt = $pdo->prepare("
    INSERT IGNORE INTO plugin_installs (license_id, plugin_slug, domain_hash, created_at) 
    VALUES (:lid, :plugin, :domain, NOW())
");
$insertStmt->execute(['lid' => $license['id'], 'plugin' => $pluginSlug, 'domain' => $domainHash]);

// 5. Обновляем общий счетчик активных установок плагина
$pdo->prepare("
    INSERT INTO plugin_stats (plugin_slug, install_count) 
    VALUES (:slug, 1) 
    ON DUPLICATE KEY UPDATE install_count = install_count + 1
")->execute(['slug' => $pluginSlug]);

echo json_encode(['status' => 'success', 'message' => 'License activated and install tracked']);

04 Шаг 3: Отображение на витрине (с акцентом на надежность)

Теперь вы можете честно писать "Активированных лицензий", а не просто "Скачиваний", что повышает ценность продукта.

</div>

<script>
document.addEventListener('DOMContentLoaded', () => {
    const pluginSlug = 'YourVendor.YourPlugin';
    const el = document.getElementById('install-count');
    
    // Эндпоинт должен отдавать данные с кэшем (Cache-Control: max-age=3600)
    fetch(`https://api.yourstudio.com/v1/public-stats?plugin=${pluginSlug}`)
        .then(res => res.json())
        .then(data => {
            el.textContent = new Intl.NumberFormat('ru-RU').format(data.count || 0);
        })
        .catch(() => {
            el.textContent = '100+'; // Fallback для сохранения социального доказательства
        });
});
</script>

05 Почему ключ (License Key) меняет всё

  • 1. Защита от накрутки: Без ключа любой скрипт может накрутить вам 10 000 "установок". С ключом счетчик растет только при реальной покупке.
  • 2. Борьба с Nulled-версиями: Вы можете видеть, сколько людей используют ваш плагин без ключа (если добавить счетчик "unknown" запросов), и при желании блокировать функционал.
  • 3. Маркетинговое преимущество: Надпись "500+ активных лицензий" продает в 3 раза лучше, чем "500+ скачиваний", потому что подразумевает реальные деньги и доверие.
  • 4. Безопасность клиента: Использование `INSERT IGNORE` и хэширования доменов гарантирует, что вы не храните персональные данные клиентов, соблюдая GDPR.
