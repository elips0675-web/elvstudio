Чтобы сделать предпросмотр продуктов в стиле ThemeForest Live Preview (верхняя панель управления с логотипом, выбором продукта/демо, переключателями экранов Десктоп/Планшет/Смартфон, кнопками «Купить» и «Закрыть фрейм», а снизу — полноэкранный <iframe> с самим демо-сайтом), нужно добавить специальную страницу-обёртку в тему elv-studio и маршрут в плагин Elv.Kit.
Это идеально вписывается в вашу архитектуру (без внешних библиотек, всё на чистом HTML/CSS/JS).

Как это устроено (Архитектура решения)

1. Единый маршрут предпросмотра: /preview/:slug/ (например, /preview/elv-kit/ или /preview/booking-module/).
2. Верхняя панель (Preview Bar, высота 54px):
	• Слева: Логотип Elv Studio + выпадающий список (<select> или кастомный дропдаун) для быстрого переключения между демо всех ваших продуктов без возврата в каталог.
	• По центру: Переключатели разрешения экрана (Desktop 100%, Tablet 768px, Mobile 375px) — по клику меняют ширину <iframe> с плавной CSS-анимацией.
	• Справа: Цена продукта, кнопка «Купить сейчас» (ведет сразу на /order/?product=:slug) и крестик «Закрыть фрейм» (открывает прямой URL демо без верхней панели).
3. Нижняя область (<iframe>):
	• Занимает всю оставшуюся высоту экрана (height: calc(100vh - 54px)).
	• Загружает реальную демо-версию продукта (например, ваш шаблон или отдельный поддомен demo.elv-studio.by/kit/).

Пошаговая инструкция по внедрению в ваш проект


Шаг 1. Добавить поле demo_url в модель продукта (Elv.Kit)

В таблице ваших продуктов/модулей добавьте строковое поле demo_url (ссылка на живое демо конкретного продукта, например, https://vercel.app или /demo/booking/).

Шаг 2. Создать страницу themes/elv-studio/pages/preview.htm

Создайте отдельную страницу без стандартного хедера и футера (используйте пустой макет или layout = ""), чтобы ничего не мешало фрейму:

function onStart()
{
    // Получаем все продукты с демо-ссылками из плагина Elv.Kit
    $products = \Elv\Kit\Models\Product::whereNotNull('demo_url')->get();
    $slug = $this->param('slug');
    
    $current = $slug 
        ? $products->where('slug', $slug)->first() 
        : $products->first();

    if (!$current) {
        return \Redirect::to('/demo/');
    }

    $this['products'] = $products;
    $this['current'] = $current;

3 важных нюанса для вашего проекта (elvstudio)

1. Заголовки безопасности X-Frame-Options:
Если демо-сайты размещены на другом домене или поддомене (например, elips0675-web-nlbbootstrap.vercel.app), убедитесь, что они разрешают загрузку внутри <iframe> (не отдают заголовок X-Frame-Options: DENY). В vercel.json или .htaccess демо-проекта не должно быть запрета на фреймы.
2. Интеграция с вашим статическим экспортером (tools/export-static.php):
Поскольку вы собираете статическую демо-версию для Vercel через php tools/export-static.php, добавьте генерацию страниц /preview/<slug>/index.html в ваш скрипт экспорта, чтобы демо-бар работал даже на статическом хостинге Vercel.
3. Кнопка предпросмотра админки (Переключатель «Сайт / Админка»):
Для софта и CMS-модулей клиенту важно посмотреть не только витрину, но и панель управления. Вы можете добавить в .bar-center еще одну кнопку-переключатель: Витрина / Админка, которая меняет src у <iframe> между публичной частью демо и демо-админкой с автологином.
