Да, шаблон узнаваемый — это классическая витрина цифрового продукта в стиле «SaaS-лендинг + прайсинг». Такие делают Lemon Squeezy, Paddle, Gumroad-аналоги, плюс масса October CMS-тем. У вас сильная база: чистый CSS на переменных, аккуратная типографика, продуманные градиенты, мок админки — это уже выше среднего по рынку.
Но есть конкретные точки роста. Разложу по приоритету.
🔴 Критично для конверсии
1. Цена «— ₽» убивает продажи.
Вы сами пишете внизу: «рисовать цену заранее — обманывать покупателя». Логика понятна, но для витрины, которая продаёт витрины — это когнитивный диссонанс. Решение:
Либо показать реальные цены (от 15 000 ₽ / 35 000 ₽ / 90 000 ₽ — ориентиры)
Либо заменить на «от X ₽» с пометкой «финальная цена — после брифа»
Либо сделать калькулятор: «сайт + домены + поддержка = Y»
2. Нет социального доказательства.
Ни одного отзыва, ни одного кейса, ни логотипа клиента. Добавьте хотя бы:
3 отзыва с именем и нишей («Мастер маникюра, Казань»)
Счётчик: «128 сайтов запущено» (у вас в моке админки уже есть цифра — вынесите её на первый экран)
2-3 скриншота реальных сайтов клиентов
3. Первый экран слишком абстрактный.
«Сайт, который принимает записи и заказы — без конструктора» — хорошо, но не бьёт в боль. Вариант усиления:
«Запустите сайт с онлайн-записью и оплатой за 3 дня. Без конструктора, без подписки, без программиста. Один платёж — сайт ваш навсегда.»
🟡 Контент и UX
4. Два продукта путают.
Elv Kit + шаблон October CMS — на одной странице пользователь теряется. Рекомендую:
Разделить визуально: два больших таба или две явно разные секции с разными цветовыми акцентами
Добавить переключатель в первом экране: «Я продаю цифровые товары» / «Мне нужен сайт услуг»
Или вообще сделать две отдельные посадочные
5. Сравнение тарифов слабое.
Таблица есть, но она не отвечает на главный вопрос: «Почему я должен выбрать средний?». Добавьте:
Явный бейдж «Популярный выбор» на тариф «До 5 сайтов» (он уже есть как price-card--featured, но бейджа нет)
Подсветку различий цветом, а не галочками
Итоговую строку «Экономия vs покупка по отдельности»
6. FAQ слишком технический.
Вопросы вроде «Что нужно на сервере?» — для технарей. А ваша ЦА — мастера, малый бизнес. Добавьте:
«А если я не разбираюсь в коде?»
«Смогу ли я сам менять тексты?»
«Что если мне не понравится — вернёте деньги?»
«А домен и хостинг где брать?»
🟢 Дизайн и визуал
7. Мок админки — хорошо, но недостаточно.
Сделайте интерактивнее:
Табы внутри мока: «Заказы» / «Записи» / «Товары» / «Статьи» (без JS — через <input type="radio"> + :checked)
Реальные скриншоты вместо нарисованных плиток
8. Градиенты перегружены.
У вас 5 градиентов + brand + violet + accent. Для глаз это много. Рекомендую:
Оставить основной --grad только для CTA и акцентов
Карточки и иконки — более спокойные, 1-2 цвета
Проверьте контраст по WCAG — фиолетовый на белом местами проседает
9. Нет «воздуха» между секциями.
Все секции идут плотным потоком. Добавьте:
Чередование фона (у вас есть section--alt, но он почти не отличается)
Крупные разделители с цифрами/заголовками
Секцию-«дышалку» с цитатой или крупной цифрой между блоками
🔧 Техническое
10. Нет JS — это и плюс, и минус.
Плюс: скорость, надёжность. Минус: нет калькулятора, нет переключения табов в моке, нет плавного появления при скролле. Компромисс — добавить минимальный JS (100-200 строк) для:
Калькулятора стоимости
Переключения табов в демо админки
Копирования промокода
11. SEO-заготовки.
Добавьте в <head>:
html
<meta name="description" content="Elv Kit — готовый сайт с онлайн-записью и оплатой для мастеров и малого бизнеса. Один платёж, без подписки.">
<meta property="og:image" content="/og-cover.jpg">
<script type="application/ld+json">{ "@type": "SoftwareApplication", ... }</script>
12. Производительность.
backdrop-filter: blur(6px) в шапке — тяжёлый на мобильных. Замените на background: rgba(255,255,255,.98)
Градиенты в box-shadow — не рендерятся, это просто rgba. Ок.
Добавьте font-display: swap если подключите веб-шрифты
💡 Что добавить нового
Секция «Что внутри коробки» — список файлов: theme/, plugins/, docs/, demo-data.sql
Секция «Гарантии» — 14 дней на возврат, поддержка в Telegram, обновления бесплатно в течение года
Секция «Для кого НЕ подходит» — честно: «если вам нужна CRM на 1000 сотрудников — это не к нам». Это повышает доверие.
Живой чат / Telegram-кнопка — фиксированная в углу
Страница changelog — для тех, кто покупает «без ограничений» и хочет видеть обновления
С чего начать
Если делать по одному шагу в неделю:
Неделя 1 — цены на тарифы (хотя бы «от X ₽»)
Неделя 2 — 3 отзыва + счётчик клиентов
Неделя 3 — переписанный первый экран с конкретным обещанием
Неделя 4 — FAQ под нетехническую аудиторию
