Промт для создания сайта на October CMS для продажи Elv Kit (универсальный конструктор)
Ниже — готовый промт, который можно передать AI-агенту (Cline, Aider, DeepSeek, ChatGPT) или разработчику. Он собран на основе всех предоставленных документов: анализа бренда, монетизации, упаковки, юридических аспектов, идей для улучшения шаблона Markit, требований к хостингу и функционалу.

🎯 РОЛЬ И КОНТЕКСТ
Ты — senior full-stack разработчик October CMS 4.x (Laravel 12, PHP 8.3) и UX-архитектор. Твоя задача — спроектировать и реализовать коммерческий сайт-лендинг на October CMS для продажи продукта Elv Kit — модульного конструктора сайтов (тема + плагины + демо-данные). Также на сайте должен быть блог для SEO-продвижения и контент-маркетинга.

💳 ИНТЕГРАЦИЯ ПЛАТЕЖЕЙ И ВЫДАЧА ДОСТУПА
Требование: после оплаты клиент автоматически получает доступ к файлам и документации.

Реализация (кастомная, без тяжёлого e-commerce):

Модель Order с полями: status, product_id, download_token, email.

Кнопка «Оплатить» создаёт заказ со статусом pending и инициирует платёж через ЮKassa (или Stripe для международных).

Перенаправление на защищённую страницу платёжного шлюза (данные карты не касаются нашего сервера).

Вебхук /payment/webhook:

Принимает POST от шлюза.

Проверяет подпись (секретный ключ).

Находит заказ по ID.

Если оплата успешна — генерирует случайный download_token, меняет статус на paid.

Отправляет письмо со ссылкой https://elv-studio.by/download/{token}.

Ссылка ведёт на защищённую страницу скачивания (проверка токена, ограничение попыток).

Альтернатива: использовать Meloncart или Mall, если нужна готовая инфраструктура. Но для лендинга с одним-двумя продуктами кастомная реализация предпочтительнее (контроль, безопасность, производительность).

Не оставлять в репозитории .env, локальные пути, внутренние заметки.
