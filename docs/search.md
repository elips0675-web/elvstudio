# Поиск по сайту и блогу

Дата среза: 18.11.2026 (Stage 49).

## Что сделано

- `/search/` — страница поиска по 27 страницам и 67 статьям блога.
- В шапке каждой страницы — кнопка поиска; форма открывается в `<dialog>`.
- Индекс: `GET /search-index.json`, собирается из `Classes\Search`.
- На странице есть фильтры «Всё / Блог / Страницы», пустое состояние и
  частые запросы.
- Страница `/search/` закрыта от индексации (`noindex, follow`), потому что
  поисковые URL с `?q=` не должны плодить дубли. Ссылка на неё есть в подвале.
- В статической демо-копии (`demo-static/`) поиск работает: экспорт пишет
  `search-index.json` и `/search/index.html`, форма помечена
  `data-static-search`, поэтому общий перехват форм её не блокирует.

## Архитектура

| Файл | Роль |
|---|---|
| `plugins/elv/kit/classes/Search.php` | индекс страниц и статей, нормализация, токены, ранжирование |
| `plugins/elv/kit/classes/Http/SeoController.php` | отдаёт `/search-index.json` с кэшем 30 минут |
| `plugins/elv/kit/routes.php` | маршрут `search-index.json` |
| `themes/elv-studio/pages/search.htm` | разметка страницы, форма, фильтры, пустое состояние |
| `themes/elv-studio/assets/js/search.js` | загрузка индекса, поиск, фильтр, `history.replaceState` |
| `themes/elv-studio/assets/css/search.css` | стили страницы; подключается только на `/search/` |
| `themes/elv-studio/partials/header.htm` | кнопка и `<dialog>` поиска |
| `themes/elv-studio/assets/js/app.js` | открытие/закрытие диалога |
| `tools/export-static.php` | `search-index.json`, страница `/search/`, разрешение формы |

Индекс — обычный JSON-массив. Запись статьи содержит `title`, `url`,
`description` (начало анонса), `text` (первые 320 символов тела без HTML),
`keywords` (рубрика, теги, аудитория), `meta` (рубрика и дата). Полное тело
статей в индекс не попадает: это держит страницу лёгкой и не раздувает
`demo-static`.

## Как ищет

1. Запрос приводится к нижнему регистру, `ё` → `е`, пунктуация заменяется
   пробелами.
2. Слова короче двух символов и служебные слова (`и`, `в`, `на`, `для`…)
   отбрасываются.
3. Совпадение всей фразы в заголовке даёт +14; слово в заголовке +7,
   в ключевых словах +5, в описании +3, в начале текста +2, в метаданных +1.
4. Результаты сортируются по сумме; показываются первые 30. Запрос не
   сохраняется и не уходит на сервер — поиск клиентский.

## Границы

- Поиск по блогу внутри `/blog/` остаётся отдельным: он ищет по опубликованным
  статьям через `Blog::paginate()` и в статике показывает подсказку. Общий
  поиск его не заменяет.
- Поиск Консультанта — следующий этап (Stage 50): он будет вызывать
  `Search::query()` и возвращать ссылки на статьи и страницы.
- Карта сайта `/sitemap/` — Stage 51: сгруппировать разделы, не выводить
  67 статей плоским списком.
- Индекс не является полнотекстовым поиском по всей статье. Если понадобится
  искать по всему телу, это отдельное решение: MySQL FULLTEXT или внешний
  индекс, с проверкой нагрузки и приватности.
