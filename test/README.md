# Папка `test` — вход для внешнего AI-аудита

Здесь лежит **самодостаточный срез витрины Elv Studio** для анализа
в браузере (DeepSeek, Qwen и другие модели без доступа к диску).

| Файл | Что внутри |
|---|---|
| `Для анализа.txt` | стек, роль площадок, что откуда (ядро/магазин/кастом), карта кода, тесты и гейты, факты HEAD, бэклог, ограничения, вопросы аудитору |

## Как пользоваться

1. Открыть `Для анализа.txt` и загрузить его в чат целиком.
2. Задать вопросы из раздела «Что смотреть аудитору» или свои.
3. Если модели нужен конкретный файл — назвать путь из карты кода
   (`plugins/elv/kit/classes/Seo.php` и т. п.); этот файл ей отдельно
   и передать.

## Что здесь **не** лежит

- Код, `.env`, пароли, дампы БД.
- `vendor/` и `modules/` (ядро October) — их нет и в репозитории.
- Полный бэклог и журнал — `Что доделать.txt` и `Что сделано.txt` в корне.

## Когда обновлять

- После каждого закрытого этапа: числа статей/страниц/гейтов и бэклог
  меняются — править разделы 5–8 и дату среза в шапке.
- Перед отправкой на аудит проверить HEAD (`git log --oneline -1`) и то,
  что числа совпадают с фактическим прогоном `npm run check`.

Файл коммитится в репозиторий (`test/` не в `.gitignore`).
