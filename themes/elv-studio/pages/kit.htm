Требования

Сервер и хостинг

Ничего экзотического: обычный shared-хостинг с PHP, MySQL и cron. Подойдёт Fly Старт и любой аналог с SSH или панелью.

  • {{ elv_icon('check')|raw }} PHP 8.3+, расширения mysqli, pdo_mysql, mbstring, json, curl, zip
  • {{ elv_icon('check')|raw }} MySQL 8.0+ или MariaDB 10.6+, кодировка utf8mb4
  • {{ elv_icon('check')|raw }} 512 МБ памяти и 1 ГБ диска под демо-данные
  • {{ elv_icon('check')|raw }} HTTPS и домен — для оплаты и писем
  • {{ elv_icon('check')|raw }} cron раз в минуту для очереди писем
