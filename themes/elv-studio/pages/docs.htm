Всё, что нужно, чтобы поднять сайт с нуля: от требований до вебхука оплаты. Инструкция проверена на October CMS 4.4.13, PHP 8.3.30 и MySQL 8.4.

1. Требования

  • {{ elv_icon('check')|raw }} PHP 8.3+ с расширениями mysqli, pdo_mysql, mbstring, json, curl, zip, gd
  • {{ elv_icon('check')|raw }} MySQL 8.0+ или MariaDB 10.6+, utf8mb4
  • {{ elv_icon('check')|raw }} Composer 2 и доступ к SSH либо распаковка архива через панель
  • {{ elv_icon('check')|raw }} 512 МБ памяти PHP, 1 ГБ диска
  • {{ elv_icon('check')|raw }} HTTPS-сертификат и домен
  • {{ elv_icon('check')|raw }} cron раз в минуту — очередь писем и ночное обновление слотов

2. Установка

Есть два пути: чистая установка October CMS и распаковка архива поверх неё.

Чистая установка

composer create-project october/october site
cd site
php artisan october:migrate
php artisan october:env
php artisan key:generate

В .env укажите доступ к базе и адрес сайта:

APP_URL=https://example.ru
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_DATABASE=elv_studio
DB_USERNAME=elv
DB_PASSWORD=secret

Архив с темой и плагином

Распакуйте содержимое архива в корень установки, чтобы получилось два каталога:

themes/elv-studio/
plugins/elv/kit/

Затем примените миграции и создайте администратора:

php artisan october:migrate
php artisan october:admin
php artisan elv:kit:demo

Активная тема — elv-studio. Плагин включается сам, как только появился в plugins/.

3. Настройки плагина

Админка → Elv Kit → Настройки. Пять вкладок:

  • Бренд — название, слоган и описание для микроразметки.
  • Контакты — e-mail, телефон, Telegram, WhatsApp, GitHub, адреса документации и демо. Из них собирается виджет и футер.
  • Виджет — включение ИИ-консультанта. Он отвечает по каталогу и настройкам, без внешних API.
  • Продажи — валюта, режим оплаты, копия заказа, ключи ЮKassa и Stripe.
  • Лицензии и SEO — токен API, счётчик активаций, коды аналитики.
{{ elv_icon('info')|raw }}

Ключи лучше держать в .env, а не в базе: настройки попадают в дамп и в бэкапы.

4. Оплата и вебхуки

Сервер не принимает карты. Заказ создаётся в базе, покупатель уходит на страницу шлюза, оплата фиксируется вебхуком.

ЮKassa

YOOKASSA_SHOP_ID=123456
YOOKASSA_SECRET=live_...

URL для уведомлений: https://example.ru/payment/yookassa. Событие — payment.succeeded.

Stripe

STRIPE_SECRET=sk_live_...
STRIPE_WEBHOOK_SECRET=whsec_...

Endpoint: https://example.ru/payment/stripe. События: checkout.session.completed и checkout.session.async_payment_succeeded.

Режимы

  • auto — реальный шлюз, если ключи есть; mock только вне production и без ключей.
  • live — только шлюз. Без ключей заказ сохраняется, оплата отвечает 503.
  • mock — заказ сразу помечается оплаченным. В production запрещён.

5. Почта и очередь

Письма ставятся в очередь, поэтому без cron они не уходят. Минимальный набор:

MAIL_MAILER=smtp
MAIL_HOST=smtp.example.ru
MAIL_PORT=587
MAIL_USERNAME=noreply@example.ru
MAIL_PASSWORD=secret
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=noreply@example.ru

QUEUE_CONNECTION=database

Cron на хостинге:

* * * * * cd /home/user/site && php artisan schedule:run >> /dev/null 2>&1

6. Лицензии и API

После оплаты заказ получает ключ вида ELV-XXXX-XXXX-XXXX-XXXX и лимит доменов по тарифу. Активация — отдельным запросом:

POST /api/v1/license/activate
Content-Type: application/json

{"license_key":"ELV-...","product":"elv-kit","domain":"example.ru","version":"1.0.0"}

Статистика активаций: GET /api/v1/license/stats?product=elv-kit. Публичность переключается в настройках.

7. Демо-данные

  • php artisan elv:kit:demo — добавить недостающие товары, статьи, категории и слоты. Идемпотентно.
  • php artisan elv:kit:demo --refresh-slots — обновить расписание броней.
  • php artisan elv:kit:reset — стереть демо-контент и сообщения, затем создать заново.
  • php artisan elv:kit:package — собрать ZIP поставки из текущей темы и плагина.

8. Обновление

  1. Сделайте дамп базы и копию themes/elv-studio и plugins/elv/kit.
  2. Загрузите новые файлы, не удаляя storage/ и .env.
  3. Выполните php artisan october:migrate и php artisan cache:clear.
  4. Проверьте главную, заказ, бронь и админку.

Обновления не перезаписывают ваши правки в теме: если меняли шаблоны — сравните с новой версией вручную.

9. Типовые ошибки

500 после переноса на хостинг

Права на storage/ и bootstrap/cache/, затем php artisan cache:clear и php artisan october:migrate. Проверьте версию PHP — 8.3 обязательна.

419 Page Expired

Сессия не сохраняется: проверьте SESSION_DRIVER, права на storage/framework/sessions и что домен в APP_URL совпадает с адресом в браузере.

Письма не приходят

QUEUE_CONNECTION указывает на очередь, а cron не настроен. Проверьте php artisan queue:work --stop-when-empty вручную.

Нет свободных слотов

Слоты генерируются на будни на три недели вперёд. Запустите php artisan elv:kit:demo --refresh-slots.

429 Too Many Requests

Формы — 20 запросов в минуту с IP, чат — 40. Лимиты Laravel; при необходимости меняются в plugins/elv/kit/routes.php.
